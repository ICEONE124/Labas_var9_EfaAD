2. ТАБЛИЦА ТЕСТ-КЕЙСОВ 

Тест №1. Деление скаляра на ноль
- Входные объекты: Индекс 0 (4) / Индекс 1 (0)
- Ожидаемый результат: Операция невозможна (деление на ноль запрещено)

Тест №2. Сложение скаляра и вектора-строки (проверка несовместимости типов)
- Входные объекты: Индекс 0 (4) + Индекс 2 ([1, 2])
- Ожидаемый результат: Операция невозможна для данных типов

Тест №3. Сложение скаляра и матрицы (проверка отсутствия бродкастинга)
- Входные объекты: Индекс 0 (4) + Индекс 7 (Матрица 2x2)
- Ожидаемый результат: Операция невозможна для данных типов

Тест №4. Деление скаляра на вектор и матрицу
- Входные объекты: Индекс 0 (4) / Индекс 2 ([1, 2]) и Индекс 0 (4) / Индекс 7 (Матрица 2x2)
- Ожидаемый результат: Операция невозможна для данных типов

Тест №5. Скалярное произведение двух векторов-строк одинаковой длины
- Входные объекты: Индекс 2 ([1, 2]) * Индекс 3 ([3, 4])
- Ожидаемый результат: [Скаляр]: 11.0000

Тест №6. Скалярное произведение двух векторов-столбцов одинаковой длины
- Входные объекты: Индекс 5 ([1; 2]) * Индекс 6 ([3; 4])
- Ожидаемый результат: [Скаляр]: 11.0000

Тест №7. Внутреннее произведение вектора-строки на вектор-столбец (1x2 * 2x1)
- Входные объекты: Индекс 2 ([1, 2]) * Индекс 6 ([3; 4])
- Ожидаемый результат: [Скаляр]: 11.0000

Тест №8. Внешнее произведение вектора-столбца на вектор-строку (2x1 * 1x2)
- Входные объекты: Индекс 5 ([1; 2]) * Индекс 3 ([3, 4])
- Ожидаемый результат: [Матрица] (размер 2x2):
  3.0000  4.0000
  6.0000  8.0000

Тест №9. Попытка деления однотипных векторов и матриц
- Входные объекты: Индекс 2 / Индекс 3 (векторы) и Индекс 7 / Индекс 8 (матрицы)
- Ожидаемый результат: Операция невозможна для данных типов

Тест №10. Сложение векторов-строк разной длины (1x2 + 1x3)
- Входные объекты: Индекс 2 ([1, 2]) + Индекс 4 ([1, 2, 3])
- Ожидаемый результат: Операция невозможна (несовпадение размерностей)

Тест №11. Умножение несогласованных матриц (2x3 * 2x3)
- Входные объекты: Индекс 9 (Матрица 2x3) * Индекс 9 (Матрица 2x3)
- Ожидаемый результат: Операция невозможна (число столбцов первой != числу строк второй)

Тест №12. Умножение согласованных прямоугольных матриц (2x3 * 3x2)
- Входные объекты: Индекс 9 (Матрица 2x3) * Индекс 10 (Матрица 3x2)
- Ожидаемый результат: [Матрица] (размер 2x2):
   58.0000   64.0000
  139.0000  154.0000
